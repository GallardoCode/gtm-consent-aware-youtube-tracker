# Project instructions

## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues. Before reading, creating, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the default triage labels. Before triaging or applying labels, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single context with root `CONTEXT.md` and `docs/adr/`. Before exploring the codebase or proposing changes, read `docs/agents/domain.md`.
